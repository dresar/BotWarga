# Program Kesehatan

## Informasi

Desa Pulosarok memiliki berbagai program kesehatan yang bertujuan untuk meningkatkan derajat kesehatan masyarakat. Berikut informasi lengkap mengenai program kesehatan di Desa Pulosarok:

## Program Kesehatan Unggulan

1. Desa Siaga Sehat
   - Program kesiapsiagaan desa dalam menangani masalah kesehatan
   - Pembentukan tim siaga desa yang terdiri dari kader kesehatan
   - Sistem peringatan dini dan penanganan kasus darurat
   - Pertemuan rutin setiap bulan untuk evaluasi

2. Gerakan Masyarakat Hidup Sehat (GERMAS)
   - Kegiatan senam bersama setiap hari Minggu pukul 06.00 WIB di lapangan desa
   - Pemeriksaan kesehatan gratis setiap 3 bulan sekali
   - Penyuluhan pola hidup sehat
   - Lomba desa bersih dan sehat antar dusun

3. Program Pencegahan Penyakit Menular
   - Pemberantasan sarang nyamuk (PSN) setiap minggu
   - Pemantauan jentik nyamuk oleh kader jumantik
   - Fogging berkala pada musim hujan
   - Penyuluhan pencegahan penyakit menular

4. Program Kesehatan Lansia
   - Posyandu lansia setiap tanggal 25 setiap bulan
   - Senam lansia setiap hari Sabtu pukul 07.00 WIB
   - Pemeriksaan kesehatan rutin
   - Pemberian makanan tambahan untuk lansia

5. Program Kesehatan Remaja
   - Penyuluhan kesehatan reproduksi di sekolah
   - Pembentukan kader kesehatan remaja
   - Konseling kesehatan remaja setiap hari Rabu
   - Kegiatan olahraga bersama setiap hari Sabtu sore

## Jadwal Kegiatan

1. Senam Sehat
   - Hari: Minggu
   - Jam: 06.00-07.30 WIB
   - Tempat: Lapangan Desa Pulosarok
   - Peserta: Seluruh warga desa

2. Posyandu Lansia
   - Hari: Setiap tanggal 25 (atau hari kerja terdekat jika tanggal 25 libur)
   - Jam: 08.00-11.00 WIB
   - Tempat: Balai Desa Pulosarok
   - Peserta: Warga lansia (usia 60 tahun ke atas)

3. Penyuluhan Kesehatan
   - Hari: Setiap hari Jumat minggu ketiga
   - Jam: 13.00-15.00 WIB
   - Tempat: Balai Desa Pulosarok
   - Peserta: Seluruh warga desa

4. Kerja Bakti Desa Bersih
   - Hari: Minggu pertama setiap bulan
   - Jam: 07.00-10.00 WIB
   - Tempat: Seluruh wilayah Desa Pulosarok
   - Peserta: Seluruh warga desa
